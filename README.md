# 🎁🎰 بوت روليت هدايا تلغرام

بوت ترفيهي بايثون لعبة "روليت" داخل كروب أصدقاء — **بدون فلوس أو مراهنات**، فقط لعبة إقصاء عشوائي حتى يبقى فائز واحد.

مبني بمكتبة [`python-telegram-bot`](https://docs.python-telegram-bot.org/) ويحفظ حالة كل كروب في قاعدة بيانات SQLite محلية.

---

## 1) طريقة بدء جولة جديدة

### الطريقة الأساسية: وضع الإنلاين (Inline Mode)
1. داخل الكروب، اكتب `@اسم_البوت` (بدون أي كلمة بعده).
2. يظهر خيار واحد اسمه **"ابدأ روليت هدايا تلغرام"** — اضغط عليه.
3. يرسل البوت تلقائياً داخل نفس الكروب البطاقة التفاعلية فيها قائمة المشاركين (فارغة بالبداية) وتحتها **زرّان**:
   - ✅ **Join | انضمام**
   - 🎰 **Spin | لف الروليت**

### الطريقة الاحتياطية: `/roulette`
إذا لم يعمل وضع الإنلاين لأي سبب (مثلاً لم يُفعّل من BotFather بعد)، استخدم أمر `/roulette` داخل الكروب — يرسل نفس البطاقة بنفس الزرّين مباشرة.

> ⚠️ كل جولة مرتبطة **حصراً** بالكروب الذي بدأت فيه (عبر `chat_id`) — بدء جولة في كروب لا يؤثر إطلاقاً على أي كروب آخر.

> إذا كانت هناك جولة نشطة بالفعل (بدأ السبين ولم يُعلن فائز بعد) ومحاول أحد بدء جولة جديدة عبر الإنلاين أو `/roulette`، يرد البوت بتحذير ولا يصفّر الجولة الحالية.

### ⚙️ ملاحظة تقنية مهمة حول الإنلاين
رسائل الإنلاين لا تكشف لتيليجرام الـ `chat_id` الحقيقي للأزرار المرفقة بها مباشرة (خاصية خصوصية من تيليجرام نفسه)، لذلك أزرار مرفقة مباشرة برسالة إنلاين تبقى "عالقة" بدون استجابة عند الضغط عليها. لتفادي هذي المشكلة، رسالة الإنلاين هنا تُستخدم فقط كإشارة انطلاق نصية بسيطة، والبوت يستبدلها فوراً برسالة بوت عادية فيها البطاقة التفاعلية الحقيقية — وهذا النوع من الرسائل يكشف الـ `chat_id` بشكل طبيعي فتشتغل الأزرار بثبات 100%.

## 2) طريقة اللعب بالأزرار

- كل من يريد المشاركة يضغط زر **✅ Join | انضمام** أسفل البطاقة:
  - **لا يُرسل أي رسالة جديدة بالكروب.**
  - تظهر له رسالة تأكيد سريعة فوق المحادثة (Popup من تيليجرام نفسه) تقول "✅ تم انضمامك للروليت".
  - البطاقة تتحدّث تلقائياً وتضيف اسمه لقائمة المشاركين مباشرة (مرقّمة، وبعلامة 🟢).
- لما يصير عدد كافٍ من المشاركين (اثنان فأكثر)، **الشخص اللي بدأ الجولة فقط** (اللي اختار "ابدأ روليت هدايا تلغرام" من الإنلاين أو نفّذ `/roulette`) يقدر يضغط زر **🎰 Spin | لف الروليت**:
  - أي شخص ثاني يحاول يضغطه يوصله رد "🚫 بس الشخص اللي بدأ هذي الجولة يقدر يلف الروليت."
  - يقصي البوت مشاركاً عشوائياً **ويرسل رسالة فعلية بالكروب** بصيغة `❌ تم إقصاء @username من الروليت`.
  - البطاقة تتحدّث وتحط علامة ❌ مُقصى جنب اسم من أُقصي.
  - ملاحظة: الشخص اللي بدأ الجولة يقدر يلف الروليت حتى لو هو نفسه ما ضغط Join وما دخل كلاعب — هذا التقييد بس على "مين يحق له يضغط سبين"، مو على المشاركة نفسها.
- استمروا بالضغط على **🎰 Spin** كل مرة لإقصاء مشارك إضافي، حتى يبقى واحد فقط — عندها تُرسل رسالة `🏆 مبروك! الفائز بروليت هدايا تلغرام هو @username 🎉` بالكروب وتختفي الأزرار من البطاقة.

### بديل نصي (اختياري، للي يفضل الكتابة بدل الأزرار)
| الأمر / الكلمة | الوظيفة |
|---|---|
| `/join` أو كتابة `بوك` | نفس عمل زر Join (بدون Popup، لأن ذلك متاح فقط عبر ضغط الأزرار — يبقى صامتاً بالنجاح العادي، ويرد برسالة فقط بالحالات الاستثنائية أدناه) |
| `/spin` | نفس عمل زر Spin — يرسل رسالة الإقصاء/الفائز بالكروب دائماً |
| `/players` | عرض عدد المشاركين وأسمائهم الحاليين |
| `/reset` | تصفير جولة **هذا الكروب فقط** (لا يمسح جولات الكروبات الأخرى) |
| `/help` أو `/start` | شرح مختصر للأوامر |

### سلوك الانضمام المتكرر
- **بالزر:** يرد دائماً بـ Popup مناسب لكل حالة (انضمام ناجح / تكرار / خسارة / اكتمال العدد).
- **بالكتابة (بوك أو /join):** الانضمام الناجح العادي **صامت** (بدون رسالة، فقط تتحدث البطاقة الثابتة)، لكن يردّ برسالة بالكروب فقط بهذي الحالات المهمة:
  - ثاني مرة يحاول الانضمام → `كافي مو لحيت`
  - ثالث مرة وما فوق → `دطير أنت مشترك أصلاً`
  - إذا تم إقصاء مشارك وحاول الانضمام مرة أخرى بنفس الجولة → `انت خسرت يا فاشل`
  - عند اكتمال 10 لاعبين → `اكتمل عدد اللاعبين!`

### أثناء الإقصاء
- كل ضغطة على 🎰 Spin (أو `/spin`) تقصي مشاركاً واحداً عشوائياً **وترسل رسالة فعلية بالكروب**: `❌ تم إقصاء @username من الروليت` (يُعرض `@username` إن وجد، وإلا الاسم الأول فقط — **لا يُعرض أي آيدي رقمي أبداً**).
- عند بقاء مشارك واحد فقط: تُرسل رسالة `🏆 مبروك! الفائز بروليت هدايا تلغرام هو @username 🎉` بالكروب، وتختفي الأزرار من البطاقة.
- بعد أول إقصاء تُقفل الانضمامات لنفس الجولة تلقائياً.

## 3) التشغيل محلياً (اختباري)

### المتطلبات
- Python 3.10 أو أحدث

### الخطوات
```bash
# 1. إنشاء بيئة افتراضية (اختياري لكن مستحسن)
python -m venv venv
source venv/bin/activate      # على ويندوز: venv\Scripts\activate

# 2. تثبيت المتطلبات
pip install -r requirements.txt

# 3. ضبط التوكن كمتغير بيئة
export BOT_TOKEN="ضع_توكن_البوت_هنا"     # على ويندوز (PowerShell): $env:BOT_TOKEN="التوكن"

# 4. تشغيل البوت
python bot.py
```

يمكنك الحصول على `BOT_TOKEN` من [@BotFather](https://t.me/BotFather) على تيليجرام عبر أمر `/newbot`.

## 4) ⚠️ تنبيه مهم بخصوص Privacy Mode و Inline Mode

### أ) تفعيل Inline Mode (ضروري للطريقة الأساسية)
وضع الإنلاين **معطّل افتراضياً** ويجب تفعيله يدوياً من BotFather وإلا لن يظهر خيار "ابدأ روليت هدايا تلغرام" عند كتابة `@اسم_البوت`:

1. افتح محادثة مع [@BotFather](https://t.me/BotFather)
2. أرسل `/mybots` → اختر بوتك → `Bot Settings` → `Inline Mode` → `Turn on`
3. (اختياري) يمكنك ضبط `Inline Placeholder` من نفس القائمة ليظهر نص توضيحي في مربع الكتابة.

> ملاحظة تقنية: الرسالة التي يرسلها Telegram تلقائياً عند اختيار نتيجة الإنلاين (`via_bot`) **يراها البوت دائماً بغض النظر عن Privacy Mode** — لذا لا حاجة لتعطيل Privacy Mode خصيصاً لأجل هذه الخطوة، لكن تعطيله مطلوب لأجل كلمة "بوك" كما موضح أدناه.

### ب) Privacy Mode (ضروري لكلمة "بوك")
بشكل افتراضي، بوتات تيليجرام تعمل بوضع **Privacy Mode** المفعّل، وهذا يعني أن البوت **لن يستقبل** الرسائل النصية العادية داخل الكروب (مثل كلمة `بوك`) — بل يستقبل فقط الأوامر الصريحة مثل `/join`.

لكي تعمل كلمة `بوك` كطريقة انضمام، لديك خياران:

1. **تعطيل Privacy Mode** (موصى به):
   - من BotFather: `/mybots` → اختر بوتك → `Bot Settings` → `Group Privacy` → `Turn off`
   - أعد إضافة البوت للكروب بعد التغيير (أو أزله وأضفه من جديد) ليطبّق الإعداد.

2. **أو** جعل البوت **أدمن** في الكروب — الأدمن يرى كل الرسائل بغض النظر عن Privacy Mode.

بدون أحد الخيارين، الأزرار والأوامر مثل `/join` و`/roulette` و`/spin` و`/players` و`/reset` ستعمل بشكل طبيعي، لكن كلمة `بوك` النصية لن تصل للبوت (استخدموا `/join` بدلاً منها في هذه الحالة).

## 5) النشر على Railway

1. ارفع محتوى هذا المجلد إلى مستودع GitHub جديد (**فاضي تماماً** — لا ترفع فوق ملفات قديمة بنفس المستودع لتفادي تضارب الأسماء).
2. من لوحة Railway: **New Project → Deploy from GitHub repo** واختر المستودع.
3. من تبويب **Variables** أضف:
   - `BOT_TOKEN` = التوكن الذي حصلت عليه من BotFather
4. Railway يكتشف تلقائياً ملف `Procfile` وسيشغّل العملية كـ **Worker** (وليس Web Service) — هذا هو النوع الصحيح لأن البوت يستخدم Polling وليس استقبال HTTP.
5. تأكد أن نوع الخدمة "Worker" مفعّل (وليس متوقف/Web) من تبويب Deployments.
6. **مهم:** تأكد ما فيه أكثر من Deployment نشط بنفس الوقت لنفس البوت — تشغيل نسختين معاً بنفس التوكن يسبب تعارضاً (Conflict) في استقبال التحديثات من تيليجرام ويجعل الأزرار/الأوامر تستجيب بشكل عشوائي أو متقطع.

---

## 6) النشر على Render

1. ارفع المشروع إلى GitHub (بنفس التنبيه أعلاه: مستودع فاضٍ بدون تضارب أسماء).
2. من Render: **New → Background Worker** (مهم: ليس Web Service، لأن البوت لا يفتح منفذ HTTP).
3. اختر المستودع، واضبط:
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python bot.py`
4. من تبويب **Environment**، أضف متغير:
   - `BOT_TOKEN` = التوكن الخاص بالبوت
5. اضغط **Create Background Worker** وانتظر اكتمال النشر.

> نفس ملاحظة Railway بخصوص استمرارية ملف SQLite تنطبق هنا أيضاً — إن أردت تخزيناً دائماً استخدم **Persistent Disk** من Render وحدد `DB_PATH` ليشير لمسار داخل ذلك القرص (متغير بيئة اختياري، افتراضيًا `roulette.db`).

## 8) ملاحظات تصميم

- كل جولة مرتبطة حصراً بـ `chat_id` الخاص بها — سواء بدأت عبر الإنلاين أو `/roulette`، وكذلك `/reset` يمسح فقط بيانات الكروب الذي نُفّذ فيه الأمر، ولا يؤثر على أي كروب آخر يستخدم نفس البوت.
- لا يتم عرض أي `user_id` رقمي في أي رسالة — فقط `@username` أو الاسم الأول.
- إذا حاول أحد بدء جولة جديدة (عبر الإنلاين أو `/roulette`) أثناء وجود جولة نشطة (تم السبين ولم يظهر فائز بعد)، يرد البوت بتحذير ولا يصفّر بيانات الجولة الجارية.
- أزرار الجولة مرفقة دائماً برسالة بوت عادية (وليس برسالة إنلاين مباشرة) لضمان استجابتها بثبات — راجع القسم 1 لتفاصيل السبب التقني.
- اللعبة بالكامل نصية وترفيهية بحتة، بدون أي رهانات أو تعاملات مالية.
